Data Deletion Instructions

Last updated: April 2, 2026

The Meta Ads Manager Tool is a private, internal application that does not store Facebook user data on external servers. However, if you wish to remove any data associated with this application's Facebook App from Meta's systems, follow the instructions below.

Note: Because this application uses a System User token (not Facebook Login for end users), no personal user data is collected or stored by this application. The steps below apply to revoking application permissions within Meta's platform.

How to Remove App Permissions from Your Facebook Account

To delete all data associated with this application and revoke its access to your Facebook account:

  1. Log in to your Facebook account.
  2. Go to Settings & Privacy → Settings.
  3. In the left sidebar, click Apps and Websites.
  4. Find Meta Ads Manager Tool in the list of active apps.
  5. Click Remove next to the app.
  6. Check the box that says "Also delete all activity this app has posted on your behalf" if shown.
  7. Click Remove to confirm.

For Business Manager / System User Access

If this application was authorized via a System User in Meta Business Manager:

  1. Go to Meta Business Manager Settings.
  2. Navigate to Users → System Users.
  3. Select the System User associated with this application.
  4. Click Remove or revoke the access token by clicking Generate New Token (this invalidates the old one).

What Data Is Deleted

When you remove the app or revoke the System User token:

  • All API access permissions granted to this application are immediately revoked
  • Any tokens associated with this application are invalidated
  • No residual data needs to be deleted from our servers, as this application does not persist Facebook data externally
