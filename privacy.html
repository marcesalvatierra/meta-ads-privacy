Privacy Policy

Last updated: April 2, 2026

This Privacy Policy describes how the Meta Ads Manager Tool (the "Application") collects, uses, and handles information when you use it to manage Meta (Facebook) advertising accounts.

1. About This Application

The Meta Ads Manager Tool is a private, internal application used exclusively by its owner to manage, monitor, and optimize Meta advertising campaigns via the Meta Marketing API. It is not a public-facing product and does not serve end-user customers.

2. Information We Access

The Application accesses the following data through the Meta Marketing API, solely on behalf of the authorized account owner:

  • Ad account information (account name, currency, timezone, status)
  • Campaign, ad set, and ad data (names, budgets, targeting, status)
  • Ad performance metrics and insights (impressions, clicks, spend, ROAS)
  • Business Manager data associated with the authenticated system user

3. How We Use the Information

All data accessed through the Meta Marketing API is used exclusively to:

  • Generate performance reports and analytics for the account owner
  • Create, update, and manage advertising campaigns on behalf of the account owner
  • Provide consulting and optimization recommendations

We do not sell, share, transfer, or disclose any data to third parties.

4. Data Storage

The Application does not persistently store Meta user data. API responses are processed in memory and displayed to the account owner. No personal data is written to external databases or third-party services.

5. Authentication & Security

The Application authenticates using a System User Access Token generated through Meta Business Manager. This token is stored locally in environment variables and is never transmitted to any external service other than the official Meta Graph API endpoints.

6. Third-Party Services

The Application communicates exclusively with Meta's Graph API (graph.facebook.com). No other third-party services receive any data.

7. Data Retention

No user data is retained by the Application beyond the duration of an active API session. Locally cached credentials (access tokens) are stored only on the account owner's device and can be deleted at any time.

8. Your Rights

As this Application is used solely by its owner to manage their own ad accounts, standard data subject rights (access, deletion, portability) are fully within the owner's control via Meta Business Manager settings. To request deletion of any data associated with Facebook Login, see our Data Deletion Instructions.

9. Changes to This Policy

This policy may be updated periodically. Any changes will be reflected on this page with an updated date.
